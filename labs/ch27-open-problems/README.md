# Known limitations for the café concierge, plus three experiments

Write a one-page note titled "Known limitations" for the café concierge. Address it to a teammate who will run the helper next month. Use four headings: a rule that goes out of date, a score that can hide a wrong answer, a long job or a screen of clicks, and who is trusted in a sale.

Then name three experiments you would run next. The three shapes are stock, graders, and resume and confirm. Each one says what you hold still, what you change, and which finished outcome you score. The chapter explains the four limits in everyday words. It uses the Tuesday restock only as a short example, so you do not need a list of names or product codes. This folder does not contain solution code.
