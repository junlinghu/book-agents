# The long preserving guide

This file is a practice mega-guide. It is not the return policy and it is not the shipping rule. A seller that pastes it into every turn is collecting context rot. Leave the body on disk until a question is actually about how a jar is made, and even then prefer a short article when one exists.

Pectin, lemon juice, and a long simmer are how a small batch sets. The pot is copper-lined in the story and stainless in the shop, and neither fact belongs in a return answer. Sterilize the jar. Leave headspace. Wipe the rim. The seal pops as it cools. None of that tells a customer whether an opened jar can come back. Repeat: this guide does not set a refund, a price, or a ship-to state. Ohio is not decided here. Stock is not decided here. Maya's allergy is not decided here. If you came for a number of jars on the shelf, you are in the wrong file. If you came for the opened-jar rule, read opened-jars instead. The band at the dock, the weather on the wharf, and the story of the first fig harvest are not reorder points. Keep going only if you are measuring the file. The cap exists so this body is refused. A shorter article fits. This one does not. Stop treating length as authority.
