# Mill picnic

The mill picnic is chatter, not a shelf count. Someone brought a spare blanket.
The band might play after four if the rain holds. Do not use this note to order
coffee, milk, or buns. It is long on purpose so a paste-everything prompt wastes
the context budget. The oat milk count is not in this note. The Thursday bun
count is not in this note. Repeat: this file is not an order, not a price, and
not a policy. A concierge that stuffs it into every turn is collecting context
rot. Keep the title in the catalog and leave the body on disk until a question
is actually about the picnic. The band, the blanket, and the weather are not
reorder points. Filing this beside the oat-milk note without a selector makes
the next morning question worse, not better. Stop reading here if you came for
a number of cartons.
